5. 下一步实验优先级
优先级实验验证什么
1stage3 从 stage2 step6000 继续，而不是 release拆分“full DiT 解冻”和“错误 warm start”两个变量。
2冻结 action head/proprio，只解冻 video patch + 少量 video blocks确认 action/proprio 大漂移是否是策略崩盘直接原因。
3给 z_mem 加 identity consistency loss验证 memory latent 分布偏移是否可被约束。
4把 memory 设计成 z_single + gated_residual(history)让 gate=0 在数学上严格 no-op。
